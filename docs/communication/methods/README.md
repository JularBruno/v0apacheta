## Rules for numbers

1. **No figure goes public until it's verified at the original.** The transcripts we
   started from are automatic and contain garbled or conflicting numbers.
2. Every number in a method file sits in a *Numbers to verify* table with status
   ⬜ unverified / ✅ verified (+ source and date).
3. Prefer **ranges and principles** ("10–20% sobre capital a largo plazo") over precise
   figures from a talk.
4. Economics goes stale: a verified number gets an "as of" date (matches the blog's
   "Actualizado el…" rule in `CLAUDE.md`).
